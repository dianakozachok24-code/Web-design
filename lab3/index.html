Основний вміст

Адаптивна верстка допомагає сторінці зручно виглядати на екранах різного розміру.

1

HTML

Створює структуру сторінки.

2

CSS

Відповідає за оформлення елементів.

3

Float

Дозволяє розміщувати блоки поруч.

4

Media queries

Змінюють оформлення під розмір екрана.
